ARENA STUDIO - ANDROID BUILD PROJECT  (generated by arena_exe_builder 3.5.0)

Game version : 13.35.0
Package id   : org.arenastudio.arenastudiobuildv1

HOW IT BUILDS
  GenAPK.py is the unmodified GenAPK script. genapk_arena.py runs its steps (init Buildozer, update the spec, build) and applies
  the Arena settings from buildozer.arena.spec on top, because GenAPK alone only builds a Kivy WebView demo.

BUILD
  Linux / macOS : bash build_apk.sh
  Windows       : use the compiler's "Android APK" target (runs this inside WSL), or in WSL: bash build_apk.sh
  Cloud         : push these files to GitHub and run the workflow in .github/workflows/build_apk.yml
The finished APK appears in the bin/ folder.

INSTALL ON YOUR PHONE
  1. Copy the .apk to the phone (USB, cloud drive, etc.) and open it, allowing "install unknown apps" when asked.
  2. Or with USB debugging on:  adb install -r bin/<file>.apk

WHAT THE PHONE VERSION DOES DIFFERENTLY (arena_android_shim.py)
  - tkinter does not exist on Android: file/message dialogs behave as if cancelled.
  - The window is fullscreen and scaled so the game keeps its own coordinates.
  - Touch acts as the left mouse button; press and hold still for about half a second = right-click.
  - Projects and settings are saved in the app's private storage.
  - Windows-only extras (ffmpeg.exe, DLLs) are not included. Anything needing ModernGL/desktop OpenGL
    (such as the 3D viewport) must be skipped by the game when the import fails.
Set ARENA_ANDROID_SCALED=0 or ARENA_ANDROID_LONGPRESS=0 in the shim's environment to turn a patch off.

IF A CRASH HAPPENS
  arena_android_crash.log is written to the app's private storage, and `adb logcat -s python` shows the traceback.
